# Spec: Organizer Dashboard

## Purpose
Панель организатора: мониторинг продаж в реальном времени, управление возвратами, статистика агентств.

## Requirements

### REQ-DASH-ORG-001: Мониторинг Продаж
Организатор должен видеть продажи в реальном времени.

**Scenarios:**
1. **Панель мониторинга**
   - WHEN организатор отправляет GET /organizer/events/:eventId/dashboard
   - THEN система возвращает:
     - totalSeats, availableSeats, reservedSeats, soldSeats
     - totalRevenue, projectedRevenue

2. **Real-time обновление**
   - WHEN организатор подключается к WebSocket /ws/organizer/:eventId
   - THEN система отправляет обновления при каждом изменении продаж
   - AND данные обновляются в течение 1 секунды

### REQ-DASH-002: Статистика Мероприятий
Организатор должен видеть детальную статистику.

**Scenarios:**
1. **Общая статистика**
   - WHEN организатор отправляет GET /organizer/stats
   - THEN система возвращает:
     - количество мероприятий (по статусам)
     - общий доход
     - средний чек
     - конверсия просмотров -> продаж

2. **Статистика по мероприятию**
   - WHEN организатор отправляет GET /organizer/events/:eventId/stats
   - THEN система возвращает:
     - продажи по категориям мест
     - динамика продаж по дням
     - процент заполняемости

### REQ-DASH-003: Управление Агентствами
Организатор может назначать агентства и видеть их статистику.

**Scenarios:**
1. **Назначение агентства (ORGANIZER)**
   - WHEN организатор отправляет POST /organizer/events/:eventId/agencies
   - THEN система связывает агентство с мероприятием

2. **Статистика агентств**
   - WHEN организатор отправляет GET /organizer/events/:eventId/agencies/stats
   - THEN система возвращает продажи и комиссии по каждому агентству

### REQ-DASH-004: Управление Возвратами
Организатор управляет запросами на возврат.

**Scenarios:**
1. **Просмотр запросов (ORGANIZER)**
   - WHEN организатор отправляет GET /organizer/returns/pending
   - THEN система возвращает все ожидающие возврата

2. **Массовые операции**
   - WHEN организатор отправляет POST /organizer/returns/bulk-action
   - THEN система массово одобряет или отклоняет возвраты
