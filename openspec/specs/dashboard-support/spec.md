# Spec: Support Dashboard

## Purpose
Панель оператора поддержки: просмотр заказов, ручные операции, история действий.

## Requirements

### REQ-DASH-SUP-001: Просмотр Заказов
Оператор поддержки должен видеть заказы и помогать пользователям.

**Scenarios:**
1. **Поиск заказа**
   - WHEN оператор отправляет GET /support/orders?query=<email|orderId|ticketId>
   - THEN система возвращает найденные заказы

2. **Детали заказа**
   - WHEN оператор отправляет GET /support/orders/:id
   - THEN система возвращает полный заказ с:
     - данными покупателя
     - списком билетов
     - историей статусов
     - запросами на возврат

### REQ-DASH-SUP-002: Ручные Операции
Оператор может вручную отменять или подтверждать заказы.

**Scenarios:**
1. **Ручная отмена заказа**
   - WHEN оператор отправляет POST /support/orders/:id/cancel
   - THEN система отменяет заказ
   - AND освобождает места
   - AND записывает действие в audit_log

2. **Ручное подтверждение заказа**
   - WHEN оператор отправляет POST /support/orders/:id/confirm
   - THEN система подтверждает заказ
   - AND записывает действие в audit_log

### REQ-DASH-SUP-003: История Действий
Система должна вести историю действий по каждому заказу.

**Scenarios:**
1. **Просмотр истории**
   - WHEN оператор отправляет GET /support/orders/:id/history
   - THEN система возвращает chronological список всех действий:
     - { action, userId, timestamp, details }

2. **Аудит действий оператора**
   - WHEN оператор выполняет любое действие
   - THEN система записывает в audit_log:
     - { action, supportId, targetOrderId, timestamp, ip }
