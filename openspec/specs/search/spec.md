# Spec: Search

## Purpose
Полнотекстовый поиск мероприятий по названию, дате, месту, жанру.

## Requirements

### REQ-SEARCH-001: Поиск Мероприятий
Система должна поддерживать поиск мероприятий с фильтрами.

**Scenarios:**
1. **Поиск по тексту**
   - WHEN пользователь отправляет GET /events/search?q=<query>
   - THEN система ищет по названию и описанию мероприятия
   - AND возвращает результаты в порядке релевантности

2. **Фильтр по дате**
   - WHEN пользователь отправляет GET /events/search?date=2026-11-01
   - THEN система фильтрует мероприятия по дате
   - AND возвращает события на указанную дату

3. **Фильтр по месту**
   - WHEN пользователь отправляет GET /events/search?city=Moscow
   - THEN система фильтрует мероприятия по городу/месту проведения

4. **Фильтр по жанру**
   - WHEN пользователь отправляет GET /events/search?genre=concert
   - THEN система фильтрует мероприятия по жанру
   - AND поддерживает: concert, theater, sport, conference, festival, other

5. **Комбинированные фильтры**
   - WHEN пользователь отправляет GET /events/search?q=rock&date=2026-11-01&genre=concert
   - THEN система применяет все фильтры одновременно

6. **Пагинация**
   - WHEN пользователь отправляет GET /events/search?page=1&limit=20
   - THEN система возвращает пагинированный результат
   - AND включает totalCount для навигации

### REQ-SEARCH-002: Полнотекстовый Поиск
Система использует PostgreSQL Full-Text Search.

**Scenarios:**
1. **Индексация**
   - WHEN мероприятие создано или обновлено
   - THEN система обновляет tsvector индекс для поиска

2. **Ранжирование**
   - WHEN результаты поиска возвращаются
   - THEN они ранжируются по tsrank (вес заголовка > вес описания)

### REQ-SEARCH-003: Только опубликованные мероприятия
**Scenarios:**
1. **Фильтр по статусу**
   - WHEN пользователь ищет мероприятия
   - THEN система возвращает только мероприятия со статусом 'APPROVED'
