# Spec: Admin Dashboard

## Purpose
Панель администратора: управление пользователями, модерация мероприятий, настройка комиссии платформы.

## Requirements

### REQ-DASH-ADM-001: Управление Пользователями
Администратор управляет пользователями и ролями.

**Scenarios:**
1. **Список пользователей**
   - WHEN администратор отправляет GET /admin/users
   - THEN система возвращает пагинированный список пользователей
   - AND включает: id, email, role, createdAt, status

2. **Блокировка пользователя**
   - WHEN администратор отправляет POST /admin/users/:id/block
   - THEN система блокирует пользователя
   - AND отзывает все active токены

3. **Разблокировка пользователя**
   - WHEN администратор отправляет POST /admin/users/:id/unblock
   - THEN система разблокирует пользователя

### REQ-DASH-ADM-002: Модерация Мероприятий
Администратор модерирет мероприятия.

**Scenarios:**
1. **Очередь модерации**
   - WHEN администратор отправляет GET /admin/events/pending
   - THEN система возвращает мероприятия со статусом 'PENDING'
   - AND включает: id, title, organizer, createdAt, description

2. **Одобрение мероприятия**
   - WHEN администратор отправляет POST /admin/events/:id/approve
   - THEN статус меняется на 'APPROVED'

3. **Отклонение мероприятия**
   - WHEN администратор отправляет POST /admin/events/:id/reject
   - THEN статус меняется на 'HIDDEN'

### REQ-DASH-ADM-003: Настройка Комиссии Платформы
Администратор настраивает процент комиссии платформы.

**Scenarios:**
1. **Получение текущей комиссии**
   - WHEN администратор отправляет GET /admin/settings/commission
   - THEN система возвращает текущий процент комиссии

2. **Изменение комиссии**
   - WHEN администратор отправляет PATCH /admin/settings/commission
   - THEN система обновляет процент комиссии
   - AND комиссия применяется ко всем новым заказам организаторов

### REQ-DASH-ADM-004: Глобальная Аналитика
Администратор видит глобальную аналитику платформы.

**Scenarios:**
1. **Общая аналитика**
   - WHEN администратор отправляет GET /admin/analytics
   - THEN система возвращает:
     - totalUsers (по ролям)
     - totalEvents (по статусам)
     - totalRevenue
     - totalOrders
     - activeUsers (last 7 days)
     - revenueByPeriod
