# Spec: Agency Dashboard

## Purpose
Панель агентства: просмотр назначенных мероприятий, продажа билетов, статистика продаж и комиссий.

## Requirements

### REQ-DASH-AGY-001: Назначенные Мероприятия
Агентство должно видеть назначенные мероприятия.

**Scenarios:**
1. **Просмотр мероприятий**
   - WHEN агентство отправляет GET /agency/events
   - THEN система возвращает все мероприятия, назначенные агентству

2. **Детали мероприятия**
   - WHEN агентство отправляет GET /agency/events/:eventId
   - THEN система возвращает полную информацию о мероприятии

### REQ-DASH-AGY-002: Продажа Билетов
Агентство может продавать билеты через платформу.

**Scenarios:**
1. **Покупка билетов от имени агентства**
   - WHEN агентство отправляет POST /agency/orders с seatIds
   - THEN система создаёт заказ с agencyId
   - AND применяет агентскую комиссию

2. **Отслеживание продаж**
   - WHEN агентство продает билеты
   - THEN система обновляет статистику продаж агентства

### REQ-DASH-AGY-003: Статистика Продаж
Агентство должно видеть собственную статистику.

**Scenarios:**
1. **Общая статистика**
   - WHEN агентство отправляет GET /agency/stats
   - THEN система возвращает:
     - totalTicketsSold
     - totalRevenue
     - totalCommission
     - salesByEvent
     - salesByDate

2. **Real-time обновление**
   - WHEN агентство подключается к WebSocket /ws/agency/stats
   - THEN система отправляет обновления при каждой продаже
