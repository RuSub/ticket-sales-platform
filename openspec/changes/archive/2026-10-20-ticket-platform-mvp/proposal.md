# Proposal

## Why

Необходима платформа для продажи билетов на мероприятия с поддержкой множественных ролей (покупатель, организатор, агентство, администратор, поддержка) и способная выдерживать пиковые нагрузки до 10 000 запросов/сек при продаже ограниченного количества мест без двойных продаж.

## What Changes

- Введение платформы продажи билетов с полным жизненным циклом: создание мероприятия, бронирование, оплата, возврат
- Поддержка 5 ролей с разграничением прав доступа (RBAC)
- Реальное время обновления статусов мест через WebSocket
- Резервирование мест с таймаутом и гарантией отсутствия двойных продаж
- Эмулированный платёжный шлюз с подготовкой к интеграции реального
- Панели управления для организаторов, агентств, администраторов и поддержки
- Гибкие шаблоны схем залов с настраиваемыми категориями мест

## Capabilities

### New Capabilities
- `user-auth`: аутентификация (JWT + OAuth2), авторизация (RBAC), управление пользователями и ролями
- `event-management`: CRUD мероприятий, шаблоны схем залов (JSONB), категории мест, модерация
- `seat-booking`: выбор мест, корзина, резервирование с таймаутом, real-time статусы через WebSocket
- `order-payment`: создание заказов, Saga pattern, эмуляция платёжного шлюза, генерация QR-билетов
- `returns`: запросы возвратов, подтверждение организатором, освобождение мест
- `dashboard-organizer`: панель организатора — мониторинг продаж, управление возвратами, статистика агентств
- `dashboard-agency`: панель агентства — статистика продаж и комиссий
- `dashboard-admin`: панель администратора — управление пользователями, модерация, настройка комиссии
- `dashboard-support`: панель поддержки — просмотр заказов, ручные операции, история действий
- `search`: полнотекстовый поиск мероприятий (PostgreSQL Full-Text) по названию, дате, месту, жанру
- `notifications`: отправка электронных билетов на email, уведомления о статусе

## Impact

- **Новый проект**: NestJS модульный монолит, PostgreSQL, Redis, Kafka
- **API**: REST API + WebSocket endpoint
- **Зависимости**: NestJS, TypeORM/Prisma, PostgreSQL, Redis, Kafka, Socket.IO, Passport.js
- **Инфраструктура**: Docker Compose для разработки и staging
