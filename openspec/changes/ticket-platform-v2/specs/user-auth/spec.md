# Spec Delta

## ADDED Requirements

### Requirement: Buyer Invitation Acceptance

Система SHALL приглашать нового покупателя по email и позволять ему задать пароль по одноразовой
ссылке.

#### Scenario: Создание приглашения
- **WHEN** агентство продаёт места на email, которого нет в системе
- **THEN** система создаёт неактивированного покупателя и отправляет письмо со ссылкой-приглашением
- **AND** ссылка действует ограниченное время и может быть использована один раз

#### Scenario: Принятие приглашения
- **WHEN** пользователь открывает ссылку и отправляет `POST /auth/accept-invite` с паролем
- **THEN** аккаунт активируется, пароль сохраняется в виде bcrypt-хэша
- **AND** пользователь получает access/refresh-токены

#### Scenario: Просроченное приглашение
- **WHEN** ссылка просрочена или уже использована
- **THEN** система возвращает 400 и не активирует аккаунт
