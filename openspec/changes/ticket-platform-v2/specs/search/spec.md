# Spec Delta

## ADDED Requirements

### Requirement: Fuzzy and Short-Query Search

Система SHALL находить мероприятия при опечатках и коротких запросах, сохраняя ранжирование и
фильтры.

#### Scenario: Опечатка в запросе
- **WHEN** пользователь ищет `концрт` вместо `концерт`
- **THEN** система возвращает релевантные события через `pg_trgm` similarity
- **AND** результаты отсортированы по похожести и дате

#### Scenario: Короткий запрос
- **WHEN** запрос короче 3 символов
- **THEN** система использует trigram/ILIKE-поиск вместо FTS
- **AND** возвращает только `APPROVED` события

#### Scenario: FTS не дал результатов
- **WHEN** FTS-запрос вернул пустой список
- **THEN** система повторяет поиск через trigram с порогом похожести
- **AND** не дублирует уже найденные события
