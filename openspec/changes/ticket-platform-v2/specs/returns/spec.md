# Spec Delta

## ADDED Requirements

### Requirement: Refund Settlement

Система SHALL доводить возврат средств до терминального статуса и отражать его в заказе и возврате.

#### Scenario: Успешный возврат
- **WHEN** провайдер подтверждает возврат средств
- **THEN** refund становится `REFUNDED`, заказ — `REFUNDED`, возврат — `APPROVED`
- **AND** места становятся `AVAILABLE`

#### Scenario: Возврат в обработке
- **WHEN** провайдер принял запрос, но подтверждение ещё не пришло
- **THEN** refund остаётся `REFUND_PENDING`, заказ — `PAID`
- **AND** статус доступен через `GET /returns/:id`

#### Scenario: Повторное подтверждение
- **WHEN** приходит повторное подтверждение по уже завершённому refund
- **THEN** система не меняет статусы и возвращает успешный ответ
